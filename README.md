# DoorDesk ERP 🏋️

A full-stack gym management ERP built for modern fitness centers. DoorDesk ERP
streamlines daily gym operations — from member onboarding and attendance
tracking to billing, trainer scheduling, equipment maintenance, and business
analytics — all in one role-based dashboard.

## Features

- **Member Management** — profiles, membership plans, status tracking (active/frozen/expired)
- **Attendance** — real-time check-in/check-out logging with duration tracking
- **Payments & Billing** — auto-generated invoices, payment status, revenue reports
- **Trainers & Classes** — trainer profiles, specializations, group class scheduling
- **Equipment Tracking** — inventory, maintenance schedules, operational status
- **Reports & Analytics** — revenue trends, attendance patterns, membership breakdowns
- **Role-Based Access** — Admin, Trainer, and Member roles with Supabase RLS

## Tech Stack

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth, Row-Level Security)
- **Charts**: Recharts
- **Icons**: Lucide React
